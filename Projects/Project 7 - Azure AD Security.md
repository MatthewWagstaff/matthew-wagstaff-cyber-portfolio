# Project 7 — Azure AD Security

## Objective
Improve Azure AD security posture by implementing identity protection controls and reducing the risk of unauthorised access.

## Tools
Azure AD, Microsoft Entra ID, Conditional Access

## Detection / Risk Focus
- Identified identity-based risks such as weak authentication and potential unauthorised access  
- Focus placed on strengthening authentication and monitoring suspicious login activity  

## Actions
- Enabled Multi-Factor Authentication (MFA) to strengthen account security  
- Configured Conditional Access policies to control access based on location, device, and risk level  
- Improved Secure Score by applying recommended security configurations  
- Enabled identity protection alerts to detect suspicious sign-in activity  

## Validation
- Verified MFA enforcement across user accounts  
- Confirmed Conditional Access policies were applied correctly  
- Reviewed Secure Score improvements following configuration changes  
- Tested alerting to ensure suspicious activity would be detected  

## Outcome
Security posture improved by strengthening identity controls and increasing visibility of suspicious login activity. Demonstrated how proactive configuration can reduce the risk of account compromise in a cloud environment.
