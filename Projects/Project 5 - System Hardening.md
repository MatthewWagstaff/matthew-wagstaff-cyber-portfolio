# Project 5 — System Hardening

## Objective
Apply security hardening measures based on CIS Benchmarks to Windows and Linux systems to reduce attack surface and improve overall system security.

## Tools
CIS Benchmarks, Windows 10, Ubuntu

## Approach
- Reviewed CIS Benchmark recommendations for both Windows and Linux systems  
- Identified key areas where default configurations could be strengthened  
- Focused on reducing unnecessary exposure and improving visibility through logging  

## Hardening Actions
- Enabled and configured firewall rules to restrict unnecessary inbound and outbound traffic  
- Applied audit policies to improve visibility of system and authentication activity  
- Disabled unnecessary services to reduce potential attack vectors  
- Secured SSH configuration (e.g. disabling root login, enforcing stronger authentication settings)  
- Improved system logging to ensure key events are captured for monitoring and investigation  

## Validation
- Verified configurations were successfully applied across both environments  
- Confirmed improved logging and visibility of system activity  
- Checked that only required services and ports remained accessible  

## Outcome
System hardening successfully reduced the attack surface and improved monitoring capability. Demonstrated how applying baseline security standards can strengthen system resilience and support detection of suspicious activity.
