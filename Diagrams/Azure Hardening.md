# Azure AD Hardening Flow

This diagram outlines the approach taken to improve Azure AD security by strengthening identity controls and monitoring capabilities.

**Flow:**

Identify Risk → Apply Controls → Enforce Policies → Monitor → Improve

---

## Breakdown

- **Identify Risk**  
  Reviewed identity-related risks such as weak authentication and unusual login behaviour.

- **Apply Controls**  
  Enabled MFA and configured Conditional Access policies.

- **Enforce Policies**  
  Applied access restrictions based on user behaviour, location, and risk level.

- **Monitor**  
  Enabled identity protection alerts to detect suspicious sign-ins.

- **Improve**  
  Increased Secure Score by implementing recommended security improvements.

---

This process demonstrates how strengthening identity security can reduce the risk of account compromise and improve overall cloud security posture.
