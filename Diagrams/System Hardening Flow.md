# System Hardening Flow

This diagram outlines the structured approach taken to apply and validate system hardening measures based on CIS Benchmarks.

**Flow:**

Review Baseline → Identify Weaknesses → Apply Controls → Validate → Monitor

---

## Breakdown

- **Review Baseline**  
  Reviewed CIS Benchmark recommendations for Windows and Linux systems.

- **Identify Weaknesses**  
  Identified default configurations and services that could introduce security risk.

- **Apply Controls**  
  Implemented firewall rules, audit policies, service restrictions, and secure configurations.

- **Validate**  
  Confirmed changes were applied correctly and systems were functioning as expected.

- **Monitor**  
  Ensured logging and visibility were in place to detect future suspicious activity.

---

This process demonstrates a structured approach to reducing attack surface and improving system security through baseline hardening.
